## Development on this project itself

See [nens-meta's documentation](https://nens-meta.readthedocs.io) for an explanation of
the config files like `.editorconfig` and tools like `pre-commit` and `uv`.

The standard commands apply:

    uv sync
    uv run pytest
    uv run python  # You can also activate the virtualenv in .venv
    prek run --all  # You can also do 'prek install'
    uv add some-dependency
